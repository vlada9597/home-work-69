# Home Work 69 — Mongo Shell: Операції з базами даних і документами

## Мета
Закріпити навички роботи з MongoDB через Mongo Shell:
- Основні операції з документами (insert, find, update, delete)
- Агрегаційні операції
- Робота з індексами та оптимізація запитів

---

## Структура скрипта `home-work-69.js`

### Завдання 1: Основні операції з документами
1. Підключення до бази `studentDB`
2. Створення колекції `assignments`
3. Додавання 5 студентів з полями: `name`, `subject`, `score`
4. Пошук студентів з балом > 80
5. Оновлення одного документа (збільшення балу на 5 для студентів з балом < 85)
6. Видалення студента з найнижчим балом
7. Виведення тільки імен та балів студентів

### Завдання 2: Агрегаційні операції
- Групування студентів за предметом
- Обчислення середнього балу по кожному предмету
- Виведення тільки тих предметів, де середній бал > 75

### Завдання 3: Робота з індексами
1. Створення унікального індексу для поля `name`
2. Пошук студентів, імена яких починаються на `'A'`
3. Перевірка використання індексу за допомогою `explain("executionStats")`

---

## Запуск скрипта

1. Відкрити **PowerShell**.
2. Переконатися, що сервер MongoDB запущений:
net start MongoDB

Виконати скрипт:
mongosh "C:\Users\admin\Desktop\Fullstack JS\JS\home-work-69\home-work-69.js"

---------------

Перевірити результати:

find() — вставлені та оновлені документи

Агрегація — середній бал > 75

explain("executionStats") — використання індексу

-----

Примітки
Скрипт можна запускати кілька разів без помилок, завдяки автоматичному очищенню колекції assignments.

Усі дії з документами та індексами відображаються в консолі Mongo Shell.

Для коректної роботи скрипта не використовуй команду use studentDB всередині JS-файлу — замість цього використовується db = db.getSiblingDB("studentDB");.
